DOCUMENTO DE CONTENIDO DEL SITIO WEB "Mis compras"

=== 1. Resumen general del proyecto ===
Nombre visible: Mis compras / TiendaOnline
Tipo de proyecto: marketplace e-commerce con publicación de productos, gestión de usuarios y carrito de compras.
Tecnologías principales:
- Frontend: HTML, CSS, JavaScript
- Backend: PHP
- Base de datos: MySQL (conexión desde conexion.php)
- Recursos adicionales: archivos multimedia e imágenes en carpetas locales.

Arquitectura:
- Páginas HTML estáticas con partes dinámicas inyectadas por JavaScript.
- Componentes compartidos: barra de navegación y pie de página cargados mediante JavaScript.
- Backend PHP expone endpoints JSON para obtener categorías, productos, login, registro, checkout, ventas y más.
- Almacenamiento local en browser: carrito en localStorage y sesión de usuario en localStorage.

Carpeta extra encontrada: bakend/ (servidor Node.js independiente con rutas para usuarios, productos y pedidos). Puede ser un backend alternativo o un proyecto adicional no integrado directamente con el frontend PHP actual.

=== 4. Scripts JavaScript clave y sus responsabilidades ===

=== cargar-componentes.js ===
Función principal:
- Carga `navegacion.html` y `pie-pagina.html` en páginas que los usan.
- Inicializa el menú hamburguesa, resalta la página activa y actualiza el menú según la sesión.
- Inicia el buscador que envía consultas a php/buscar_productos.php.
- Contiene la lógica de búsqueda en el header y la inyección de resultados.

=== verificar-sesion.js ===
- Archivo de compatibilidad que evita 404, la lógica real de sesión se maneja en cargar-componentes.js.

=== login.js ===
Funcionalidad:
- Captura el formulario de login.
- Envía credenciales a php/login.php por POST.
- Procesa la respuesta JSON.
- Guarda `id_usuario` y `nombre_usuario` en localStorage si el login fue exitoso.
- Redirige a perfil.html después de un login exitoso.
- Muestra alertas y manejo de errores si la respuesta no es válida.

=== productos.js ===
Funcionalidad:
- Obtiene productos agrupados por categoría desde php/obtener_productos_por_categoria.php.
- Renderiza secciones de categoría y tarjetas de producto.
- Permite filtrar para mostrar sólo productos propios del usuario logueado.
- Muestra mensajes si no hay productos o si el usuario no tiene productos publicados.

=== buscar.js ===
Funcionalidad:
- Realiza búsqueda de producto por texto usando php/buscar_productos.php.
- Realiza búsqueda por categoría usando php/buscar_por_categoria.php.
- Crea tarjetas de producto dinámicamente.
- Maneja rutas de imagen con múltiples intentos de directorio.
- Actualiza el título de resultados según la búsqueda.

=== carrito.js ===
Funcionalidad:
- Almacena el carrito en localStorage con clave `miTienda_carrito_v1`.
- Agrega, elimina y limpia items del carrito.
- Calcula el total del carrito.
- Realiza checkout enviando los datos a php/checkout.php.
- Muestra modal de éxito y redirige a gracias.html.
- Renderiza la interfaz del carrito en carrito de compras.html.

=== otros scripts JS importantes ===
- perfil.js: probablemente maneja datos del perfil de usuario y carga de información en perfil.html.
- perfil-producto.js: probablemente carga la ficha de producto y detalles del vendedor.
- mis_productos.js: administra la lista de productos del usuario si está logueado.
- modal-registro.js y registro-modal.js: controlan la apertura/cierre de modales y la UI de registro.
- vender.js: maneja el proceso de publicación de productos desde vender.html.
- acera.js y destacados.js: scripts auxiliares específicos de las secciones de la página `acerca.html` y destacados en el home.

=== 5. Backend PHP y API ===

=== conexion.php ===
Detalles de conexión a la base de datos:
- Host: 127.0.0.1
- Usuario: root
- Contraseña: (vacía)
- Base de datos: tienda_online
- Puerto: 522

=== php/registro.php ===
- Registra un usuario nuevo.
- Valida campos vacíos.
- Hashea contraseña con password_hash.
- Evita correos duplicados.
- Responde JSON con éxito o error.
- Mensajes:
  - ⚠️ Faltan campos.
  - 🎉 ¡Registro exitoso!
  - ❌ Error al registrar el usuario.
  - ⚠️ Este correo ya está registrado.

=== php/login.php ===
- Procesa login de usuario.
- Verifica contraseña con password_verify.
- Inicia sesión PHP y devuelve datos de usuario.
- Responde JSON.
- Mensajes:
  - Faltan campos.
  - Inicio de sesión exitoso
  - Contraseña incorrecta.
  - Correo no registrado.

=== php/vender.php ===
- Publica un producto nuevo.
- Verifica sesión activa o recibe id_vendedor.
- Valida nombre, descripción y precio.
- Maneja imagen principal obligatoria.
- Inserta producto en BD y guarda imágenes extra.
- Usa transacción SQL para mayor integridad.
- Mensajes:
  - No hay sesión activa. Inicia sesión para publicar.
  - ⚠️ Todos los campos son obligatorios.
  - ⚠️ Debes subir al menos la imagen principal.
  - ⚠️ Error al subir la imagen principal a la carpeta.
  - ✅ Producto publicado correctamente.
  - ❌ Error: [mensaje de error interno]

=== php/obtener_categorias.php ===
- Devuelve todas las categorías ordenadas por nombre.
- JSON con `exito: true` y `categorias`.

=== php/obtener_productos_por_categoria.php ===
- Recupera productos con categoría y vendedor.
- Une tablas productos, categorias y usuarios.
- Agrupa productos por categoría.
- Responde JSON con `categorias` y lista de productos.

=== php/obtener_producto.php ===
- Probablemente devuelve detalles de un solo producto.

=== php/obtener_productos_por_categoria.php ===
- Devuelve productos agrupados para la vista de catálogo.

=== 7. Observaciones adicionales ===
- El sitio usa localStorage para persistir carrito y sesión.
- Muchas páginas dependen de datos dinámicos; sin PHP o sin servidor, las páginas quedan parcialmente estáticas.
- El frontend y backend están diseñados para trabajar juntos en un entorno LAMP.
- Hay un backend Node.js adicional en `bakend/` que sugiere otra posible versión o API no usada por el frontend actual.
- El documento generado ahora tiene un contexto completo para que una IA entienda:
  1) qué hace el sitio
  2) qué páginas contiene
  3) qué endpoints expone
  4) qué datos maneja cada parte
  5) cómo se almacena la sesión y el carrito

=== 8. Cómo usar este documento para la IA ===

- Confirmar que `conexion.php` usa puerto 522 y base `tienda_online`.
- Verificar que los scripts consumen JSON con claves `exito`/`success` y `mensaje`/`message`.
- Tratar `bakend/` como un proyecto Node.js paralelo, no integrado si se requiere la versión actual PHP.
